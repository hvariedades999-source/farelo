# SFX Studio

App web para gravar, editar e aplicar efeitos em sons pelo celular e exportar WAV para o Godot.

Abrir: https://hvariedades999-source.github.io/sfx-studio/

- Gravação com forma de onda ao vivo
- Edição não destrutiva: corte, reverter, fades, normalizar
- Cadeia de efeitos reordenável e presets próprios
- Mixagens em camadas
- Exportação WAV (compartilhar/Drive ou salvar), em lote, e MP3 para WhatsApp
